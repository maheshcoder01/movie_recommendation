## 🧠 How To Run

✅ 1. Download or Clone the Project
git clone https://github.com/your-username/movieverse.git
Or download the ZIP and extract it.

✅ 2. Open the Project Folder

Make sure the structure looks like:
MovieVerse/
 ├── index.html
 ├── movie.js
 └── assets/ (optional)

✅ 3. Run the Project
Option A — Open Directly (Easiest)
Just double-click:
index.html
The app will open in your browser.

Option B — Run With Live Server (Recommended)
If you use VS Code:
Install the Live Server extension
Right-click index.html
Select “Open with Live Server”
This gives auto-refresh + fewer CORS issues.🫡🔥
